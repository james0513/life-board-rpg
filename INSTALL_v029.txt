人生棋盤 v0.29：卡牌交鋒整合更新

適用已正常運作的 v0.27，或已套用 v0.28 的同一個專案。
這一包已合併 v0.28 音效、職業裝備與定回合魔王，不必先裝兩個更新。

1. 關閉遊戲，先複製整個原專案做備份。
2. 將 ZIP 內 life-board-rpg-v0.29-overlay 的所有內容合併覆蓋至原專案根目錄（pubspec.yaml 同一層）。保留原 assets，不要另建空專案。
3. 在原專案根目錄依序：
   flutter pub get
   flutter analyze
   flutter test
   flutter run -d chrome
4. 沿用原本瀏覽器、網址及連接埠。不要 flutter clean、清除網站資料或按重開新人生。

新戰鬥
- 普通怪物／前五魔王：五張手牌、雙方各自行動條、倒數90秒。
- 選一張或多張同系武器，可搭魔法牌；不能混武器系或只出魔法。行動條滿後按出牌，沒有SP費用。
- 出牌後自動補牌；攻防合計加上職業／裝備，魔法可百分比增強。防禦由最後出牌建立，抵擋下一擊後消耗。
- 恢復藥補HP；專注飲換入一張魔法牌並回滿行動條。
- 第六魔王是標示清楚的輪流卡牌改編，無倒數。
- v0.29.1：進入戰鬥直接開始；教學移至棋盤右上角「戰鬥卡牌教學」。右上可暫停及切換音效；切離視窗自動暫停，回來按繼續。
- 卡牌圖示是本作原創繪製，角色、裝備、六章場景與音效沿用本作素材。

參考與界線
依1999年第一代《虛擬人生》的公開畫面與玩家資料重建結構；原廠完整公式未能核實。本版卡名、數值、補牌、90秒與動畫停表、最終戰細節均為本作調整。見 docs/card_battle_design_v029.md。沒有聲稱完整復刻原作。

保留與舊存檔
- 地圖4／8／12回合自動魔王；最後落點先結算、魔王勝利才換關。
- 職業裝備限制、換職自動卸回背包、角色／金錢／道具／人生／故事全保留。
- 存檔仍格式9。從v0.28不再遷移；從v0.27使用既有.pre_v028備份流程，不重複覆蓋舊備份。不要刪除網站資料。
- 普通戰敗最多扣100；魔王戰敗不扣金，仍得到一次試煉成長。時間到平手有小額本作獎勵但不算打贏魔王。

一次驗收
1. 讀原存檔，確認角色、裝備、金錢和背包。
2. 進入普通戰鬥，先選兩張刃器，再試加魔法；故意混盾器確認不能出牌。確認只是選牌不扣血、不消耗道具。
3. 出牌確認只結算一次、即時補牌、敵方仍依自己的行動條。試魔法、回血、霜縛與音效開關。
4. 暫停／切換分頁等待後返回，確認不偷跑倒數；手動繼續。窄視窗可橫向滑動看手牌。
5. 魔王敗北或撤退仍待戰，重試勝利才換關。第六魔王確認輪流且無倒數。
6. 重開遊戲確認保存一次，沒有重複發獎。既有4／8／12地圖回合和職業裝備照常。
