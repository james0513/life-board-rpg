人生棋盤 v0.28：魔法音效、職業裝備、定回合魔王戰

這是給「已正常運作的 v0.27 專案」使用的小型覆蓋更新。

安裝
1. 關閉正在執行的遊戲，保留原專案及瀏覽器資料，先複製整個 v0.27 資料夾做備份。
2. 將 ZIP 內 life-board-rpg-v0.28-overlay 的所有內容，合併覆蓋到原專案根目錄（與 pubspec.yaml 同層）。不要另建空專案，不要刪除原 assets。
3. 在原專案根目錄開終端機：
   flutter pub get
   flutter analyze
   flutter test
   flutter run -d chrome
   或使用原 RUN_GAME.bat。
4. 沿用原本的瀏覽器、網址及連接埠。若先前使用固定連接埠，請在 flutter run 後加上原本的 --web-port 數字；不要隨意改成新網址，以免切到另一份網站儲存空間。
5. 不需要 flutter clean，不要清除網站資料，也不要按「重開新人生」。

本版變更
- 角色、普通怪物與魔王的施法有專用原創音效與施法時序；戰鬥中也能開啟／關閉音效。
- 商店新增職業系裝備，武器、防具、飾品都有職業限制提示；購買與裝備皆檢查限制，轉職不相容的裝備自動收回背包。
- 普通怪物隨關卡增加強度；六位魔王的難度依序上升。
- 每張地圖預設完成 8 回合後，自動進入魔王戰。每張地圖開始前可選 4／8／12 回合。
- 完成一個擲骰落點事件才計 1 地圖回合；選項連接戰鬥結束才算完成。人生手帳活動不增加地圖回合。
- 最後一個落點先結算完，再進入魔王戰，不會打斷購物、事件或戰鬥。
- 魔王未打贏不換關，退出／落敗仍保留待挑戰狀態。魔王落敗獲得一次體力 +2、智力 +2 的試煉心得，不扣金幣，可整備後重試；耗用道具照常扣除。普通怪物落敗規則不變。
- 魔王勝利才前往下一關並重置位置／地圖回合；第六位魔王勝利完成試煉。

舊存檔
使用原儲存位置，讀取時升級為第 9 版格式。第一次寫入新版前，會在同一網站儲存空間保留一份未改動的舊存檔備份（不重複覆蓋）；若備份失敗就暫停寫入並顯示存檔錯誤。已累積 3 場普通勝利、原本可打魔王的舊存檔，轉成 8／8 回合待挑戰；其他舊存檔保留全部既有進度，該地圖從 0／8 開始（舊版沒有記錄地圖回合，不能猜算）。
既有背包保留；不符合新職業限制的已裝備道具卸回背包，不扣錢、不刪道具。
升級後的存檔不能由 v0.27 讀取；若要退回程式版本，請使用升級前備份的網站存檔資料。進階復原可在瀏覽器開發者工具 Application → Local Storage 找到以 .pre_v028 結尾的項目，先匯出兩份內容備份，再請熟悉網站儲存的人協助還原；不要直接刪除網站資料。

一次完整驗收
1. 沿用正常存檔進入遊戲；檢查角色、金錢、背包與既有美術仍在。
2. 地圖剛開始時選 4 回合；完成第 1～3 次落點確認計數只加一次，第 4 次結算後自動開魔王戰。
3. 點戰鬥音效開關後試角色技能、冰封、治癒與爆發；等怪物／魔王 SP 滿，確認施法音效與受擊有前後順序。瀏覽器需先有點擊互動並允許分頁聲音。
4. 魔王落敗／撤退後確認仍留原關，可整理裝備再按重試；關閉重開後仍待挑戰。魔王勝利僅前進一關，回合歸零。
5. 商店比較三個裝備分類，查看職業鎖定文字；不相容商品不可購買／裝備。換職後不相容道具仍在背包。
6. 換關比較同一怪物種類的數值；最後檢查存檔、重新讀取與連續點擊沒有重複結算。
