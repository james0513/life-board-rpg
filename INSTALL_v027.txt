人生棋盤 v0.27 美術整合更新
適用：目前已正常開啟的 v0.26.1 專案。

1. 在原本執行遊戲的命令視窗按 q，結束舊程式。
2. 先備份目前整個專案資料夾，保留可運作的 v0.26.1。
3. 將 ZIP 裡面的檔案合併至「有 pubspec.yaml」的專案根目錄。
   同名檔案覆蓋。不要刪除整個 lib、assets 或平台資料夾。
   不要將 lib 放進既有的 lib 裡。
4. 使用你先前成功的相同命令重新啟動。
   一般模式：flutter run -d chrome -t lib/main.dart
   若先前有指定 web-port，請沿用原值。
   驗收模式仍須原本的 --dart-define=LIFE_ACCEPTANCE=true。

本次無新增套件、不變更存檔 schema 或存檔鍵。
一般遊戲與驗收模式仍各用獨立存檔，請確認啟動的是原本模式。
請沿用原瀏覽器、原網址及原瀏覽器設定檔；若瀏覽器來源或設定檔不同，
可能看不到原有的本機存檔，不代表存檔被本次更新刪除。
不需要按「重新開始」才能套用新美術。

一次查看新版重點：
- 標題與大地圖：羊皮紙／深綠／黃銅介面、六章新背景。
- 我的角色：男女角色、職業服裝、武器與裝備細節。
- 商店：五類商品、獨立商品插畫、購買／解鎖／試穿。
- 戰鬥：18種怪物、6位魔王、角色與場景搭配。

預覽是由實際模型與素材離線繪出，並非 Flutter 執行畫面。

若啟動有錯誤，保留第一段錯誤文字或截圖即可，不必重建專案。
