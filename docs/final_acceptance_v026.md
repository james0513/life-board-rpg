# 最後一次整合驗收清單（v0.26）

請先複製原專案為工作副本，保留原檔與存檔。完整包可另外解壓，不用覆蓋舊專案；更新包僅合併同名檔，不刪除整個lib／assets。

Windows原專案路徑與副本合併步驟見根目錄 `INSTALL_v026.txt`。

## 1. 一次完成環境與測試

在含pubspec.yaml的工作副本根目錄執行：

```bat
flutter pub get
flutter analyze
flutter test
```

這些Flutter檢查在交付環境尚未執行。如果第一步或編譯報錯，先保留完整第一段錯誤，不必再反覆安裝各版本或重建專案。

## 2. 開啟獨立驗收模式

```bat
flutter run -d chrome -t lib/main.dart --dart-define=LIFE_ACCEPTANCE=true
```

也可雙擊RUN_ACCEPTANCE.bat。Edge使用 `-d edge`。

確認標題出現「獨立驗收模式」，面板寫著不影響正式進度。右上燒杯按鈕（窄視窗在「更多遊戲操作」選單）可載入4個情境，只會取代驗收存檔。

## 3. 18歲情境：基礎操作與故事

- [ ] 開始遊戲、擲骰、逐格移動正常；連按擲骰不會多走一輪。
- [ ] 一次完整事件只前進一季；看人物、裝備、故事分頁不增加季節。
- [ ] 「人生故事」完成第一章，下一章顯示年齡門檻；重開後已選分支仍在，不能領取第二次。
- [ ] 「人生手帳」讀書、運動、社交、休息顯示正確費用；按一次只付一次。
- [ ] 工作、轉職、商店、裝備、戰鬥維持可用；職業心得在同職業工作3次後取得。

## 4. 35歲情境：關係與家計

- [ ] 看到家庭期的商街背景與格子分布，落點事件與標籤一致。
- [ ] 開啟人生故事的關係分頁，向岑雨確認伴侶；先取消再確認，取消不改人物。
- [ ] 求婚條件／費用1200清楚，先取消再確認；孩子行動由玩家主動決定。
- [ ] 養育1名孩子後，家庭資料顯示已婚與孩子1名；每季費用＝家園×10＋孩子×15。
- [ ] 閱讀資訊、重整或重試存檔不會再次收同一季生活費。
- [ ] 其他NPC的戀愛約會被阻止，但仍可聊天。

## 5. 59歲情境：戰鬥與人生階段

- [ ] 看到晚年棋盤，六關進度仍是第6關且魔王已解鎖。
- [ ] 擲骰落在戰鬥格後可挑戰最終魔王，攻擊、技能、防禦與補給正常。
- [ ] 勝利獎勵只結算一次，結束後回到棋盤，可到人生故事記錄結局。
- [ ] 在其他操作畫面存檔後返回，棋子、職業、裝備、年齡棋盤一致。

## 6. 60歲情境：結局與轉生

- [ ] 結局分頁列出符合條件的不同結局；選一個前有確認說明。
- [ ] 記錄結局不耗一季、不再發獎勵；回看保留當時快照，不能改成另一個結局。
- [ ] 到人生手帳轉生，先取消：所有狀態保持原樣。
- [ ] 再選一項心得確認轉生：回到18歲、第2世、第一關；只留下所選心得的起始加成。
- [ ] 新世代的人物關係、房屋、孩子與故事重設，但上一世結局記錄保留。
- [ ] 存檔重讀後世代、心得、結局記錄一致，不再次加成。

## 7. 正式存檔與畫面最後確認

關閉驗收模式，重新以一般指令啟動：

```bat
flutter run -d chrome -t lib/main.dart
```

- [ ] 看不到驗收情境入口；讀取的是正式存檔，驗收進度沒有取代它。
- [ ] 使用原本瀏覽器與相同網址／連接埠查看舊進度；網頁儲存空間依網址區分。
- [ ] 原職業、金錢、裝備、六關進度和v0.25世代／心得仍在。
- [ ] 窄視窗、低高度視窗與較大文字可捲動，不遮住確認／返回按鈕。
- [ ] 聲音開關、回到主畫面、視窗背景／前景不造成卡住或重複結算。

若有問題，集中提供：使用情境、操作步驟、預期與實際結果、第一段錯誤文字／截圖、瀏覽器與視窗大小。這是一份整合驗收清單，不需要逐功能另裝更新包。
