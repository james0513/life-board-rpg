# v0.27 美術整合版

## 整體方向

將原有遊戲整理成「暖色奇幻 × 手作桌遊」：象牙紙色、深綠墨色、黃銅細線、柔和陶土色，搭配有層次的微縮角色與六幅原創奇幻場景。中文文字與按鈕保留清楚對比，裝飾不遮擋操作。

## 這次完成

- 人物：男女造型、31 個職業識別，新增立體髮束、眼睛與臉部細節、裁片、滾邊、腰帶與鞋靴；裝備仍即時反映於角色。
- 怪物：18 種原有怪物增加物種紋理與配件；6 位魔王改為獨立輪廓與服裝，不再只是同一身體換色。
- 商品：31 件商品分別設計原創插畫，涵蓋 11 件武器、7 件防具、7 件飾品、2 種補品、4 種課程。
- 商店：深綠工坊招牌、店舖插畫、商品展示牌、價格／持有／解鎖資訊，以及獨立試穿鏡。試穿不購買、不換裝、不改角色數值。
- 裝備：人物展示手帳、三個裝備欄展示卡、收藏圖鑑與換裝差異；保留卸下、已裝備、忙碌中與錯誤處理。
- 六章場景：青芽學園、黃金商店街、齒輪科技城、幻彩大劇院、赤岩英雄堡、星界命運王座；每幅 1536×1024，保留中央遊玩留白。原 v18 圖片沒有覆寫。
- 棋盤：章節材質、金屬嵌線與建築細節；原座標、格子種類及角色前景繪製順序保留。
- 介面：統一標題、卡片、按鈕、對話框、選擇籤、進度條；增加人物小檔案、骰子質感、戰鬥台座與細框。
- 效能策略：背景重繪邊界、靜態人物最多 48 筆模型快取、商店改為商品插畫而非每件重繪人物。這不是裝置效能測試結果。

## 檢查方式與限制

交付包須通過以下閘門，結果保存在外附 manifest.json 與 packaged-validation.log：

1. ZIP CRC、內容逐檔雜湊與覆蓋重建一致。
2. 將「實際交付 ZIP」套到 v0.26.1 備份，逐檔使用本地 Dart parser，要求每個檔案退出碼均為 0。另以非法實體換行字串確認閘門確實拒絕 v0.26 曾發生的錯誤。
3. 同一重建目錄執行七套本地 Dart 套件：語法、生命核心、六關、年齡棋盤、故事、審查情境、完整人生整合。
4. 使用原始模型建構程式離線輸出幾何，檢查男女／職業／裝備、18 種怪物、6 位魔王及六章棋盤；檢查有限座標與預覽範圍。
5. 使用原始商品 CustomPainter 的路徑／漸層離線輸出 SVG 並檢視所有商品；確認六張 PNG 可讀且尺寸正確。

離線預覽採用輕量繪圖替身來輸出原始美術，不包含 Flutter widget 排版、GPU／CanvasKit 實際行為或完整執行環境。預覽均標示「素材／模型預覽，非實際遊戲截圖」。它們能協助檢查實際造型與素材，不能替代遊戲實跑。

**本次沒有執行 Flutter 編譯、完整 Flutter 靜態分析、Widget 測試、Windows／Chrome 畫面操作或效能測量。** 新增的 `test/atelier_art_test.dart` 僅已通過 Dart 語法解析，未冒稱 Widget 測試已執行。製作環境既有的 Flutter 工具啟動限制仍被遵守，未重試或繞過。
