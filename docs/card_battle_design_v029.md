# v0.29 卡牌交鋒：依據與改編邊界

本版是以1999年第一代《虛擬人生》的公開畫面與玩家資料為結構參考，改寫本專案的戰鬥；不是原遊戲的逐公式復刻。程式、卡名、圖像與音效使用本專案原創內容，沒有納入原作遊戲程式或擷取原作美術。

## 本版實際操作

1. 普通怪物與前五位魔王：雙方獨立蓄積行動條；你蓄滿後自行決定何時出牌，敵人蓄滿自動行動，不是每出一次牌便強制挨一次反擊。
2. 點選一張或多張同系武器牌，可追加任意魔法修正牌。不能混用刃／盾／杖系，也不能只出魔法。沒有SP出牌費用。
3. 組合的攻防相加，增傷／護盾百分比套用於合计。職業和裝備加成再納入計算。出牌時移除實體牌、即時補滿；命中時才改HP、防禦與狀態。
4. 新出牌防禦取代舊防禦；下一次攻擊以攻擊值減防禦計算，最低傷害0，然後消耗這次防禦。裝備防禦仍每擊生效。
5. 魔法包括百分比增傷／護盾、下次攻擊加成、回血、延後敵方行動。施法和命中有原創音效，並保留音量開關。
6. 恢復藥補HP；專注飲改為換入一張魔法牌並補滿行動條。仍使用原存檔同一份背包與數量。撤退成功率為本作65%。
7. 第六位魔王為明確標示的「輪流卡牌試煉」改編：雙方輪流出牌，沒有倒數。保留同系組合及魔法；沒有聲稱還原原作最終戰的專屬道具／完整規則。

## 明確屬於本作的調整

- 現有遊戲18歲開始，因此現有角色都是五張牌。手牌大小輔助規則為未滿15歲3張、15–17歲4張、18歲以上5張；不新增中學章節，也不更改舊存檔年齡。
- 主角初始行動條全滿，之後3.6秒一格；敵方初始為空，5.2秒一格。兩者独立。現有職業裝備保留攻擊、魔法、防禦、HP與會心等加成，沒有另造原作的全套速度／連擊裝備。
- 普通模式倒數90秒。只計可操作的有效戰鬥時間；動畫、手動暫停和切離視窗不計時，回到視窗需手動繼續。這是為可讀性與可及性加入的調整，不宣稱原作動畫也停表。
- 刃器牌基礎攻／防12/3或9/5；盾器5/16或7/12；杖器10/5或8/7。
- 增傷20%、護盾35%、下次攻擊+10、回血牌基礎24、霜縛延後1.8秒。敵人使用相同組合結構但另有難度係數。第六魔王半血加攻4。
- 補牌採本作隨機抽取，約25%魔法，並保證手中至少一張武器。沒有原作卡庫或固定牌序的宣稱。
- 時間到平手：金錢為獎金的1/12（最低10）、EXP為敵經驗的1/10（最低5）。魔王未勝不換關；平手有同原本魔王失敗的試煉成長。
- 保留v0.28經濟：普通落敗最多扣100金，魔王落敗不扣金並得到一次體力+2／智力+2，沒有改成原作傳聞的扣一半金錢。
- 每張地圖4／8／12個已完成落點後自動開魔王戰、勝利才换關。這是既有專案節奏，沒有更動為原作年齡門檻。

## 相容與驗證

沒有新增套件、帳號、網路服務或存檔欄位。格式9及原存檔鍵保持不變，v0.27升級仍走v0.28既有的原始資料備份／遷移。戰鬥過程不跨程序保存，和舊版一樣在結算時保存。

實際遊戲入口已使用CardBattleSession與CardBattleScreen。卡牌戰役驗證使用真實選牌、補牌、蓄力、命中及結束階段，不能透過舊版普通攻擊API繞過新系統。保留舊模型測試供既有規則回歸，但不把它們當作新卡牌玩法驗證。
