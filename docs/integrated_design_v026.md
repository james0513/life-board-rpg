# v0.26：一套可走完的人生循環

## 範圍與交付約定

單人、原創規則、沿用既有 Flutter／Flame、角色與六關美術音樂。整合完成後提供同一套程式與一份集中驗收清單，不要求逐功能安裝或分批測試。v0.25 與舊專案須保留備份。

本作參考經典人生棋盤的走格、成長、職業、試煉與轉生方向，不複製商業原作資源，不宣稱公式、劇情或操作與原版完全相同。

## 從開始到結局

18 歲開始 → 擲骰並依年齡走不同棋盤 → 事件選擇、工作、轉職與學心得 → 經營交友、家園及家庭 → 完成六關試煉或走到60歲 → 選擇並記錄一個人生結局 → 決定留在本世或繼承一項心得轉生。

不強迫戀愛、婚姻、養育孩子、置產或全部戰鬥通關。完成六關或年滿60歲後，至少有一個可選結局；不會因特定人生路線而無法結束。

## 共通時間規則

- 4 個已結算回合為一年，1 次成功棋盤落點／人生行動為一季。
- 擲骰動畫、逐格經過、開啟資訊視窗、關閉選單、看結局不扣季節。
- 普通事件接戰鬥在最終戰鬥結算時才計一季，不能重複領錢、加歲或扣生活費。
- 人生故事和關係行動先驗證條件，失敗不付費、不加歲、不推進故事。
- 持有住宅／家庭後，每季還有生活費。行動費用與生活費分開列示。

## 四個年齡棋盤

20 個位置與既有存檔座標保留，商店固定在第6、16格。年齡改變後，格子分布、圖示標籤、落點實際規則與背景同步切換；六關戰鬥進度另外保留。

| 年齡 | 人生主題 | 幸運／扣款／工作／戰鬥／職業／商店格數 |
|---|---|---|
| 18–21 | 學習與探索 | 2／4／4／4／4／2 |
| 22–34 | 職業與立足 | 2／2／6／3／5／2 |
| 35–49 | 關係與家庭 | 6／4／2／2／4／2 |
| 50以上 | 回顧與傳承 | 5／2／3／3／5／2 |

所有階段都有工作、職業、商店及戰鬥機會，年齡不會封死轉職或通關。

## 連續故事

「街角的燈」「未完成的圖紙」「把日子種下」各3章，共9章，每章2種選擇。後續章節依年齡與能力開放，選擇造成不同金錢、屬性及情緒後果，也會永久記錄選過的分支。

幸運格會接續目前能進行的故事；「人生故事」亦可主動閱讀與選擇。未達條件會顯示年齡、EQ、智力、心得、家園或婚姻等原因。已完成章節不再付出／領取同一份效果；過期視窗提交必須被拒絕。

## 職業、戰鬥與成長

沿用30種職業與待業起點、前置職業及屬性門檻。每個職業累積3次工作格可得到一次永久屬性心得，轉職不抹除已學心得；原有職業主動戰鬥技能仍依現職決定。

保留六關魔王、普通戰、武器防具飾品與補給。EQ、壓力與家園影響最大HP：`(EQ−50) ~/ 10 − 壓力 ~/ 10 + 家園級數×3`，總HP最低1。數值為本作設計。

## 關係與家庭

三名原創成年角色：修復師岑雨、嚮導楚野、舞臺設計師洛青。可聊天、相約出遊；22歲且好感40以上才可確認伴侶。已選伴侶後不再向其他角色發起戀愛約會。

成家需伴侶好感70、至少1級家園及1200金錢。已婚、25–55歲且有800金錢時，可自行選擇共同養育孩子，最多2名。系統不自動增加孩子。確認伴侶、婚姻與養育前可取消。

這是精簡的成年關係系統，不含生育醫療模擬、離婚、角色衰老立繪或子女成長支線。

## 家園與金錢

- 人生手帳購買1級家園2500，升到2級再付6500。
- 每季生活費＝家園級數×10＋孩子人數×15。
- 生活費不足時金錢最多扣至0，當季壓力增加8；不生成無限負債或阻止繼續遊玩。
- 存檔記住最後付費季節；重試存檔／重開遊戲不重複扣款。舊檔升級不追繳既往回合。

## 結局與下一世

達到六關全破或60歲後，可依條件選擇：完成試煉、知識傳承、家庭、富足、平凡安穩等5種結局。每世只能凍結記錄一個結局，保存當時年齡、職業、金錢與心得數；之後繼續遊玩不改寫已記下的快照。

轉生重設本世能力、職業、裝備、家園、人物關係與故事，保留性別、世代及最近30世結局記錄，並可選一項已學心得加入新起點。未先選結局就直接轉生時，系統先記錄目前最優先符合的結局。確認視窗會事先說明。

## 存檔、操作與安全驗收

schema v8 讀取v1–v7，保留既有能力、職業、裝備、關卡、世代與心得。遇到不合法存檔不靜默覆蓋。新操作遵守存檔成功後更新人物；既有棋盤回合存檔失敗時禁止下一次擲骰並提供重試。

正式存檔鍵維持不變。驗收模式需明確以 `LIFE_ACCEPTANCE=true` 編譯啟動，使用另一個存檔鍵，並顯示醒目標示。提供18／35／59／60歲的驗收情境，縮短測試時間；一般遊戲沒有載入這些情境的入口。情境不修改正式存檔。
